# Объектная сегментация

Продолжение практикума по детекции: теперь каждому объекту нужна отдельная маска.
Основной маршрут — **01 → 02**. Полное демо с 25 микрозаданиями занимает около 60–75 минут.
Реализации и пилоты выполняем следующим блоком; длинное обучение и отчёт — самостоятельно.

Перед каждым стендом есть короткая теория с обозначениями и формулами, затем инструкция
по чтению рисунков и микрозадания. Если тема новая, сначала прочитайте этот блок;
на знакомых темах используйте его как справку во время опыта.

| Ноутбук | Содержание |
|---|---|
| [01 · Интерактивное демо](01_interactive_demo.ipynb) | 6 стендов и 25 опытов: IoU/Dice, явные пары GT, билинейная формула, 3 управляемых прототипа, два порога и сравнение моделей |
| [02 · Дообучение](02_finetuning.ipynb) | Три блока реализации, проверка разметки, исходные модели, два пилота, две длинные серии и общий test |

В основной работе нужно реализовать:

1. Преобразование карты ID в маски, рамки, классы и площади; согласованное отражение изображения и target.
2. Матрицу IoU масок и сопоставление экземпляров с учётом confidence, дубликатов и уже занятых GT.
3. Сборку масок из общих прототипов: линейную комбинацию, sigmoid после суммы и обрезку по рамке.

После каждого блока есть проверки. Незавершённый шаблон намеренно останавливается
с `NotImplementedError`. Добавьте собственные небольшие примеры и объясните результат.
Циклы обучения и общий расчёт AP уже готовы. Код интерактивного демо можно использовать.

## Модели и данные

Сравниваем **Mask R-CNN ResNet-50 FPN** и **YOLO11n-seg**: маску региона и сборку из прототипов.
Дополнительный контроль — заполненные рамки того же Mask R-CNN вместо силуэтов.
Это не третья обученная модель. Обе сети предобучены на COCO; класс person уже знаком.

[Penn–Fudan](https://www.cis.upenn.edu/~jshi/ped_html/): 170 изображений, 423 размеченных экземпляра, split **120 train / 25 val / 25 test**, seed 42.
Похожие сцены могут попадать в разные части; часть фоновых людей не размечена.
В выводах учитывайте эти ограничения. Это специализация на пешеходах, а не новый класс
или доказательство обобщения на произвольную уличную сцену.

Mask R-CNN учится на растровых масках, YOLO — на полигонах. Подготовка сохраняет отчёт
о потере точности после преобразования. В итоговой оценке для обеих моделей используются
одни и те же исходные растровые GT. Внутренние метрики тренера YOLO не подменяют общий оценщик.

## Запуск

Открыть в Google Colab:

- [01 · Интерактивное демо](https://colab.research.google.com/github/AndreySheka/applied-ai/blob/main/labs/02_segmentation/01_interactive_demo.ipynb)
- [02 · Дообучение](https://colab.research.google.com/github/AndreySheka/applied-ai/blob/main/labs/02_segmentation/02_finetuning.ipynb)

Сохраните свою копию через **Файл → Сохранить копию на Диске**. Для обучения включите
GPU через **Среда выполнения → Сменить среду выполнения**.

Используйте окружение предыдущей работы или загрузите `.ipynb` в Colab через
**Файл → Открыть блокнот → Загрузить**. Оба ноутбука самодостаточны. Для ползунков нужен
работающий Python kernel; на GitHub видны только сохранённые статические примеры.
Каждый стенд можно вызвать обычной функцией без виджетов. При запуске статичный
пример заменяется единственным интерактивным рисунком. После обновления файла
перезагрузите его с диска и выберите **Kernel → Restart Kernel and Run All Cells**.
Для каждого опыта заполняйте таблицу: прогноз, настройки, результат, объяснение.

Первая загрузка требует интернет: данные ≈52 MiB, веса Mask R-CNN ≈170 MiB и YOLO ≈6 MiB,
плюс зависимости. Загрузки проверяются по SHA-256. Кэш и результаты находятся
в `segmentation_lab_data`. Демо работает на CPU; обучение рассчитано на GPU.
Настройка общей среды — в [SETUP.md](../../docs/SETUP.md).

По умолчанию `RUN_PILOT`, `RUN_LONG` и `RUN_TEST` выключены.
Сначала заполните реализации и гипотезу. Затем запустите **обе модели по 2 эпохи**,
проанализируйте пилоты, обоснуйте настройку и выполните **обе модели по 20 эпох** заново
от COCO. Используется последняя эпоха. Test открываем после фиксации решения по val.
