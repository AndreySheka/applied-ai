## Данные и границы вывода

Это **синтетические признаки и scores**, а не признаки реальных лиц и не результат нейросети. Демонстрационные стенды используют отдельные учебные данные: стенд 2 открывает test только после фиксации порога в интерфейсе; стенд 6 сравнивает две оценки сдвига камеры на одних и тех же восьми validation query, без test. Повторный запуск стенда 2 не создает новый независимый test.

В самостоятельной работе генератор разделяет identity, сдвиг камеры и шум; это позволяет изолировать ошибку протокола. 24 train / 20 val / 20 test ID не пересекаются; три камеры известны во всех split. Учебная коррекция оценивает средние камер по train. Alpha и пороги выбираются по val, затем фиксируются перед test. Обучение большой сети здесь не требуется.

Результат относится к новым ID в известных камерах и аддитивной модели сдвига. Он не доказывает обобщение на другую камеру, качество FaceNet/OSNet или безопасность биометрической системы. Пары с одним query зависимы.
