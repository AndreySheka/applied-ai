# Критерии оценивания · 08

100 баллов. Оцениваются корректность механизма и объяснение опыта. Более низкая EPE сама по себе не добавляет баллов.

| Часть | Баллы | Проверяемый результат |
|---|---:|---|
| Интерактивные опыты | 15 | Минимум 18 строк «прогноз → параметры → число/наблюдение → объяснение»; все девять стендов; нулевой перенос и неверный знак, слабая текстура, пирамида, регуляризация, измененная маска, сравнение алгоритмов, согласованная ошибка и перенос кадра |
| Геометрия потока | 20 | Warping по grid + flow, границы, масштабирование u/v по разным осям, неизменность исходного поля |
| EPE, LK и consistency | 20 | Только GT-valid; пустая маска; наблюдаемость до ridge; обратное поле семплируется на другой сетке |
| Собственные проверки | 10 | Два новых ручных примера, asserts и указание неверной реализации, которую каждый обнаруживает |
| Контролируемый эксперимент | 20 | Одинаковые пары, заранее записанная гипотеза, val → JSON lock → test; оба метода и одна абляция; pooled EPE и честное время |
| Ошибки и выводы | 15 | Конкретная test-пара, boundary/low-texture EPE, consistency coverage; реальное видео без GT; ограничения и следующий проверяемый опыт |

Число строк относится к выбранным опытам: минимум два на стенд, включая нормальный и трудный случай. Все дополнительные микрозадания можно использовать для диагностики; не требуется оформлять отдельную строку для каждого пункта.

## Для полной сдачи

- Notebook последовательно исполняется после реализации TODO; открытые тесты проходят.
- Сохранены val/test CSV, `selection_locked.json`, одинаковые изображения для обоих методов и карта ошибок с общей шкалой.
- При resize .5 EPE считается после возврата поля в исходные пиксели. Разные значения по ширине/высоте проверены отдельно.
- Основная EPE использует одну GT-valid маску. Отдельно указано, сколько пикселей осталось после диагностического consistency filter.
- Время алгоритма отделено от чтения видео, генерации пар, графиков и времени работы студента. Указаны OpenCV, разрешение и число CPU threads.
- Дополнительные опыты явно отделены от фиксированного test. Если гипотеза не подтвердилась, это объясняется без замены данных.

Если среднее посчитано по разным маскам у разных методов или по разным единицам потока, численная таблица пока не сравнивает методы. Сначала исправьте протокол. Недостаток качества классического метода на конкретной паре не является ошибкой студента при корректной реализации и честном разборе.
